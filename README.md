# z-OS-Portfolio
Esercizi pratici su IBM z/OS svolti durante il mio percorso di formazione come z/OS System Administrator : elaborazione batch con JCL database DB2 e SQL, automazione con REXX e programmazione COBOL

/***************************************************************** INDICE REPOSITORY *****************************************************************************************/
Cosa trovi in questo repository
Area	       |  Competenze dimostrate
JCL & DFSORT |	job multi-step, allocazione e gestione dataset
DB2 & SQL    |  modellazione di relazioni uno-a-molti e molti-a-molti, chiavi esterne e indici, query di reportistica, utility UNLOAD, LOAD, RUNSTATS, REORG, COPY/RECOVER
REXX         |  Script TSO con parametri, LISTCAT, data stack (MAKEBUF, PUSH/QUEUE, PULL), compound variables
COBOL        |  programmi batch su dataset sequenziali e DB2
